Hermes Personal

Hermes Personal is a private automation setup operated by the owner of the GitHub account maxim11odessa. It uses Hermes Agent on an Ubuntu computer to assist its owner with personal productivity. It is not a public sign-up service and is not affiliated with Google.

Google integration

After the owner authorizes access, the setup can read and manage Google Calendar events; search, read and send Gmail messages; access and synchronize Google Drive files; and read or edit Google Docs and Google Sheets. These capabilities support the owner's requests and explicitly configured automations, such as calendar summaries and Obsidian note synchronization. Available operations depend on the permissions granted.

Calendar access supports agenda lookup and event management. Gmail access supports email assistance. Drive access supports file operations and note synchronization. Docs and Sheets access supports document and spreadsheet tasks.

Data processing

The setup runs on the owner's computer, but this does not mean that all data remains local. Relevant task content may be sent to the configured external AI model provider. Requested results may also be delivered through configured messaging services. See the Privacy Policy for details.
